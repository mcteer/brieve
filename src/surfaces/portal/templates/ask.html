Ask a question

Asking answers; it never acts. Nothing here starts a run, changes anything, or touches your estate — to have an agent do something, run an agent.

{# ONE FORM, ONE FIELD. No source selector and no model selector: which corpus is pinned and which model may answer are not the asker's to choose, and a control for either would be a request to widen scope. The platform decides what the question needs. #}

Answers come from the platform’s pinned documentation or from your own records — whichever fits what you asked. An answer usually takes a minute or two, so leave this page open while it works.

{# WHERE AN ANSWER LANDS. Two regions, deliberately, because they carry different kinds of thing. `ask-status` holds a SHORT sentence about what is happening and is a live region, so a screen-reader user is told the question went and later that it came back. `ask-outcome` holds the answer itself and is NOT live: announcing a page of claims the instant it arrives talks over somebody who is still reading. Focus moves to its heading instead, which is how a person gets there on purpose. #}

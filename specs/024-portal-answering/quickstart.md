# Quickstart: 024 — proving an answer is grounded, and that asking never acts

**Scenario 5 is the feature.** The rest can pass while the platform still cannot answer a person.

---

## Prerequisites

```bash
make dev-up
DEV_IDP=1 make mcp-surface-up
```

No vendor credential. Every scenario below except the last runs against a fixture provider — that
is the point.

---

## 1. The corpus is pinned, and pinned by content

```bash
ls packs/*/corpus/ && cat packs/*/corpus/PROVENANCE.md
```

**Expect**: documents, and provenance naming where they came from and when.

**Then change one byte of one document.** The recorded digest must change. **The corpus carries no
version metadata anywhere**, so if a version string is what moved, nothing is being detected.

---

## 2. A citation resolves, or it does not ship

```bash
uv run pytest tests/component -k citation -q
```

**Expect**: every citation in an answer resolves to a section of the pinned corpus.

**Then break one deliberately** — point a citation at an anchor that does not exist. The row must
fail. **An unresolvable citation is worse than none**, because it reads as evidence, and a reader
who follows it and finds nothing has been told something false about what we know.

---

## 3. Declining beats confabulating

Ask something the corpus does not cover.

**Expect**: a decline naming what was missing — **not** a plausible answer, and **not** the same
shape as a provider failure. A reader must be able to tell "the corpus does not say" from "we could
not reach the model", because one sends them to the corpus and the other to an operator.

---

## 4. Asking never acts

```bash
uv run pytest tests/conformance/answering -k never_acts -q
```

**Expect**: no effecting tool is reached, including when the question is phrased as an instruction
— *"delete the staging workspace"* is a question about what would happen, and must be answered or
declined, never performed.

**This is asserted by exercising the path, not by reading it.** ADR-0039 decided this rule before
the feature existed precisely because it would be tempted.

---

## 5. The gates score the product

```bash
make evals
```

**Expect**: `citation_accuracy` and `must_decline` green — **over output the answering path
produced**, not over authored strings.

**This is the row that would have failed before this feature.** Both suites are green today
because `FixtureScorer` replays a recording and `LiveModelScorer` asks a vendor directly; neither
has ever touched product code. Point the suite at the product path on the pre-024 tree and it
fails immediately, because there is nothing to ask.

**Then check the substitution honestly**: `git diff` the recordings. If they were regenerated by
hand rather than produced by the path, this scenario passes and means nothing — which is exactly
the state the feature exists to leave behind.

---

## 6. Both surfaces answer the same

```bash
make conformance
```

**Expect**: the ask operation present on API and MCP with the same verdicts (ADR-0033). The portal
calls the API rather than answering itself (ADR-0034).

---

## Definition of done

- Scenarios 1–4 green with **no vendor credential**
- Scenario 5 green **and** the recordings demonstrably produced by the path
- Scenario 6 green on a live enclave
- An `ask` matrix cell qualified via `make evals-live` — **owed, named in the contract**
- No answer content in the trail (FR-012)
